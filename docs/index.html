Hair Day · Guia de instalação

Como executar o projeto

Siga este guia para baixar o Hair Day, instalar as dependências e executar a aplicação com a API local no seu computador.

Acessar repositório Baixar Node.js

Antes de começar

Você precisa ter instalado:

  • Node.js — ambiente necessário para executar as ferramentas do projeto.
  • npm — gerenciador de pacotes instalado junto com o Node.js.
  • Git — para clonar o repositório.

Depois da instalação, abra o terminal de sua preferência.

Instalação e execução

1Clone o repositório

Baixe o código-fonte para o seu computador:

git clone https://github.com/Lazaro277/hair-day.git
cd hair-day

2Instale as dependências

Dentro da pasta do projeto, execute:

npm install

O npm instalará as bibliotecas necessárias para o front-end e para a API local.

3Inicie a API

Abra o primeiro terminal na pasta do projeto e execute:

npm run server

A API será iniciada em http://localhost:3333.

Para consultar os agendamentos, acesse http://localhost:3333/schedules.

4Inicie o front-end

Abra um segundo terminal, também dentro da pasta do projeto, e execute:

npm run dev

O Webpack iniciará o servidor de desenvolvimento. Abra no navegador:

http://localhost:3000
Importante: mantenha os dois terminais abertos. A aplicação precisa da API em execução para consultar, criar e cancelar agendamentos.

Comandos disponíveis

  • npm install — instala as dependências.
  • npm run server — inicia a API local.
  • npm run dev — inicia o front-end em modo de desenvolvimento.
  • npm run build — gera os arquivos de produção na pasta dist.

Sobre a API e os dados

O Hair Day utiliza o JSON Server para disponibilizar uma API REST local. Os agendamentos são armazenados no arquivo server.json, sem necessidade de configurar um banco de dados externo.

A API utiliza operações HTTP para consultar, criar e remover agendamentos. Como o serviço é local, cada pessoa precisa iniciar a API em seu próprio computador.
